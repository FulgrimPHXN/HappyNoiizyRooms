# Комнаты

Участие хранится в Room.players: Map<UUID, RoomRole> через @ElementCollection.
Владелец автоматически становится GM. Миграция V3 добавляет владельцев ранее
созданных комнат. Читать комнату по ID могут участники; изменять и удалять —
владелец. GET /api/rooms возвращает комнаты владельца.

Вступление требует кода приглашения. Повторное вступление возвращает 409,
неверный код — 403. Выход постороннего возвращает 404. Владелец не может выйти
(403), но может удалить комнату вместе с участниками. Передачи владения нет.

RoomService задаёт границы транзакций. Изменения управляемых сущностей
сохраняются через dirty checking. OSIV отключён; EntityGraph загружает
участников для DTO за пределами транзакции. Проверка доступа выполняется
внутри той же транзакции, что и изменение.

@Version защищает в том числе коллекцию участников. Устаревшая транзакция
откатывается; HTTP возвращает 409, клиент повторяет запрос. Конфликты
ограничений БД также возвращают 409 без внутренних подробностей драйвера.

Проверка: ./gradlew build. Тесты rooms используют Spring и H2, проверяют
доступ, вступление/выход, удаление с участниками и конфликт двух транзакций.
Они не проверяют миграции Flyway на PostgreSQL.
